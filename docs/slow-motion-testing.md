# 手动验证与只读采样

本说明用于验证三个配置开关及排查游戏内表现。安装和配置见 [README](../README.md)，地址与数据布局见 [时间倍率实现](time-scale-addresses.md) 和 [BT 载具实现](bt-vehicle-investigation.md)。

## 验证覆盖

| 功能 | 已验证的场景 | 验证方式 |
| --- | --- | --- |
| 人类敌人倍率减速 | 单次击昏、战斗移动及击杀后的移动响应 | 击昏倍率采样、人工体验与无 Mod 对照 |
| 机器类敌人倍率减速 | 敌人击败后的慢动作取消 | 用户实测反馈；未新增请求或倍率采样 |
| 拾取倍率减速 | 隐生虫、电气虫、开罗尔晶体 | 三种物品分别采样；修改后隐生虫采样、三种物品人工验证 |
| BT 载具强停 | 三轮巡航摩托、卡车 | 摩托车同步状态采样与人工验证；卡车人工验证 |

已记录的载具采样使用“遇敌动作：仅在首次播放”。其他选项、其他载具中断事件、资源重载后的重新应用情况尚未验证。

普通 BT 的血液回旋镖击杀及关闭敌人击败／拾取开关后的血液手榴弹击杀，没有复现倍率减速，因此本版没有普通 BT 击杀补丁。大型 BT 击败、Sam 被发现以及首次武器使用不属于本版的实现范围。

## 对照方法

1. 选择能够重复的存档、场景、目标、武器或载具。
2. 在 INI 中只改变待验证的一项，其余开关保持相同。
3. 每次改变配置后完整退出并重启，检查日志中的版本和开关值。
4. 尽量只触发一个事件，等待上一段遭遇或减速结束。
5. 分别记录移动响应、其他对象动作、镜头、声音及警告动画。
6. 比较开关为 `0` 和 `1` 的表现；需要恢复时设回原值并重启。

在运行期间移动或删除 ASI 不会撤销已经应用的修改。单凭音效、镜头或动画不能确认时间倍率变化。

## 功能检查

### 敌人击败

进入战斗并等发现 Sam 的警告效果结束，再击昏或击杀一名敌人。比较击败后立即转移位置的移动响应。

连续击败测试应另做一轮，记录每次事件和恢复时刻。效果持续或重复写入同一低值，不能单独证明计时被重置；需结合活动请求和计时字段判断。

机器类敌人已由用户实测确认同一开关有效。后续对照时记录具体敌人类型，分别保留人工观察与倍率采样结果。

### 物品拾取

在没有战斗或 BT 遭遇干扰的场景中，分别测试隐生虫、电气虫和开罗尔晶体。先确认关闭开关时可以复现减速，再重启开启对应功能做对照。

首次与重复拾取分开记录。一次拾取未出现减速，不能证明请求没有触发；“首次”的重置范围及触发间隔仍需验证。

### BT 载具

记录载具和“遇敌动作”选项，在 BT 区外开始采样后驶入。保持驾驶位，观察：

- 是否熄火、强制停止或短暂无法操控。
- 是否出现恢复启动动画。
- 奥卓德克、警告、特效、音效和灯光是否正常。

载具速度不是全局遭遇状态采样中的字段；需保留人工观察或其他直接测量，不能由状态编号推导速度。

## 只读工具

工具只申请读取权限，不注入、不调用游戏函数、不写入游戏内存。游戏文件、代码或资源检查失败时应检查实际版本与权限，不沿用其他构建的偏移。

### 时间控制快照

```powershell
python tools/probe_timescale.py --output build/analysis/runtime-snapshot.json
```

工具自动查找唯一的 `DS2.exe` 进程。读取指定请求的曲线时使用快照模式：

```powershell
python tools/probe_timescale.py --parameter-hash 0x4152CF0A --output build/analysis/human-curves.json
python tools/probe_timescale.py --parameter-hash 0x6ED5275D --output build/analysis/pickup-curves.json
```

### 时间控制连续采样

```powershell
python tools/probe_timescale.py --watch 180 --interval 0.005 --capture-active-curves --output build/analysis/time-scale-capture.jsonl
```

`--capture-active-curves` 对首次出现的活动曲线做类型验证并保存快照；`--parameter-hash` 仅支持快照，不能与 `--watch` 合用。

### BT 遭遇采样

保持一个游戏进程运行，取得实际 PID 后采样：

```powershell
$ds2ProcessId = (Get-Process -Name DS2 -ErrorAction Stop).Id
python tools/probe_bt_vehicle.py --pid $ds2ProcessId --watch 180 --interval 0.005 --output build/analysis/bt-vehicle-capture.jsonl
```

输出包括状态和资源地址、资源原始数据、按偏移记录的状态值、读取错误数。该工具不读取载具本体或速度。

## 记录与判读

| 项目 | 应记录的信息 |
| --- | --- |
| 环境 | 游戏版本、插件版本、INI 值、场景、目标／武器／载具 |
| 游戏选项 | “遇敌动作”及与本次测试有关的选项 |
| 事件 | 实际触发时间、是否混入其他事件、暂停区间 |
| 表现 | 移动响应、镜头、声音、警告与灯光 |
| 数据 | 请求哈希、倍率、状态变化、读取错误 |
| 结论 | 人工观察与内存记录分别说明，注明未覆盖范围 |

轮询间隔不是保证捕获每次变化的时间分辨率。短暂事件可能漏采；进程暂停会影响计时，不能将暂停区间计入游戏效果时长。静态字段名称、体感相似或共享写入函数均不足以证明事件使用同一个请求。
